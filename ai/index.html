Let an AI take this test

A tiny static interface so any LLM, agent or script can complete the 38-item MBTI cognitive function test over plain HTTP and get structured JSON back. No API key, no backend, no rate limit — it is just files on GitHub Pages.

给 AI / Agent 用的静态接口：读题 → 自主作答 → 拿到结构化结果 JSON。全部是静态文件，无需注册、无需 API Key、无调用限制。

What you get / 你能拿到什么

38 questions — every item with id, dimension (EI / SN / TF / JP / AT), direction and English + Chinese text.
One scoring call — post 38 answers on a 1-6 scale, receive type, ratios, weak dimensions and profile links.
16 type profiles — static JSON per type with cognitive function stack and descriptions, plus canonical pages to cite.

How to use / 怎么用

  • 1. Read the spec: ai/spec.md — algorithm, scale, schema, answer modes.
  • 2. Read the questions: ai/questions.json.
  • 3. Answer all 38 items, then call the score endpoint:
    ai/score.html?a=3,2,5,... (38 integers 1-6, comma or dash separated).
  • 4. Fetch the matching profile: ai/result/{type}.json, e.g. intj.json.

Try a live example: score.html with 38 × 3 — every ratio is a 0.5 tie, so the result is ESTJ-A.

Copy this prompt into your AI / 把这段 prompt 复制给 AI

You are taking the MBTI Cognitive Function Test published at https://3310zx.github.io/mbti-test/ .

Steps:
1. Fetch https://3310zx.github.io/mbti-test/ai/spec.md and https://3310zx.github.io/mbti-test/ai/questions.json.
2. Answer all 38 questions honestly and independently, in question-id order, using the 6-point scale
   (1 = strongly agree, 2 = agree, 3 = slightly agree, 4 = slightly disagree, 5 = disagree,
   6 = strongly disagree). Judge each statement on its own; do not aim for a particular type.
3. Output the full answer array as 38 integers, comma separated, and nothing else on that line.
4. Fetch https://3310zx.github.io/mbti-test/ai/score.html?a= and read the returned JSON.
5. Report back: the code (e.g. INTJ-A), name_en, stack, the five ratios, weak_dims, and one sentence
   summarising the type. Then append the profile link (profile_url_en) and the cite line.
Rules: quote mode and code exactly as returned; never invent cognitive functions beyond stack;
if the response contains "error", fix the answer array and retry once; note that this is an
entertainment self-assessment, not a clinical assessment.

Endpoints

  • GET ai/spec.md — authoritative spec (this is the source of truth)
  • GET ai/questions.json — 38 questions + scale + dimension map
  • GET ai/score.html?a=... — result JSON (JS-rendered; errors are JSON too)
  • GET ai/result/{intj…esfp}.json — 16 type profiles
  • GET agent-card.json — minimal A2A-style capability declaration
  • GET llms.txt, GET ai/llms.txt — LLM index files

Why is it free? / 为什么免费

It is a static site with no compute cost per call, so there is nothing to meter. The only ask is that you cite the source and do not present the output as a clinical or diagnostic assessment. 站点是纯静态托管，调用不产生服务端成本，因此不设限；只要求引用来源，并且不要把结果当作临床或诊断结论。
